## v1.0.7 - 2026-09-24

### 🤖 CI & Build

- Release tooling migrated to goreleaser v2, so releases can run again. Goreleaser's Slack announce is disabled (the GitHub Slack app posts releases).

### 🧪 Tests

- updated install-gitlab-ci.sh script

### 🔒 Security

- Bumped the Go toolchain to go1.26.8, resolving Snyk-reported vulnerabilities in the Go standard library (net/http, net/url, os).
- Bumped golang.org/x/sys to v0.44.0, golang.org/x/text to v0.39.0 and golang.org/x/mod to v0.40.0 (indirect) for Snyk-reported vulnerabilities (#62).
